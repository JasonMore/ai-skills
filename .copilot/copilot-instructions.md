# AI Skills Repository Rules

- Keep every personal skill under `skills/`. This repository is the source of truth.
- Symlink repository skills into `~/.copilot/skills/` with `./install`.
- Do not leave the only copy of a skill in a session, worktree, or user config directory.
- Validate each skill before finishing.
- Commit and push every skill change to GitHub.
- Keep new `SKILL.md` files under 200 lines. Move extra detail from longer legacy skills into `references/` when updating them.
